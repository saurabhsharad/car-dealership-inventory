
# Car Dealership Inventory System

A full-stack vehicle inventory management application built using test-driven development (TDD).

## Tech Stack

### Backend
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy 2.0
- Pydantic
- Alembic

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS

### Testing
- pytest
- HTTPX
- PostgreSQL integration tests
- Vitest
- React Testing Library
